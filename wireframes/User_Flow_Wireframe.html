User Journey Steps

1

App Discovery & Download

User discovers KimLand through marketing or word-of-mouth

Actions: Install app, create account or sign in
2

Home Page Exploration

User sees discount banner, browses brands, checks best sellers

Actions: Toggle currency, browse featured products, select brand
3

Brand Selection & WebView

User chooses Zara/Mango/H&M and enters brand's website

Actions: Switch between brands, view products, see converted prices
4

Product Discovery

User browses categories, uses search, applies filters

Actions: Search products, filter by size/price, view details
5

Add to Universal Cart

User adds items from multiple brands to single cart

Actions: Select size/color, add to cart, continue shopping
6

Cart Review & Checkout

User reviews cart items, applies promos, proceeds to checkout

Actions: Update quantities, apply discount codes, select currency
7

Payment & Delivery

User enters address, selects payment method, completes purchase

Actions: Add address, choose payment, confirm order
8

Order Tracking & Repeat

User receives confirmation, tracks order, becomes repeat customer

Actions: Track shipment, rate products, reorder favorites
